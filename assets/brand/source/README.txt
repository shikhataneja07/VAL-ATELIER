THE LOGO, AS THE STUDIO SUPPLIED IT
===================================

val-atelier-logo-2668.png           the lockup, val in #c3c1c2 and ATELIER in
                                    #686e7d. This is the master.
val-atelier-logo-2668-one-tone.png  the same lockup in a single grey.

2668 x 2668, transparent, with the artwork itself occupying 1830 x 1298 in
the middle of it.

Everything in the folder above is cut from these. They are kept here because
the logo was once resized down to 1000px and then to 420px for page weight,
and each pass cost detail that could not be got back: by the end its strokes
sat at half opacity and it read as a grey haze at any size.

TO REGENERATE, crop to the artwork's own edges first, then scale:
  val-atelier-mark-light.webp   the whole lockup, colours untouched, for dark
                                grounds: the splash, the hero, the curtain,
                                the footer.
  val-wordmark.webp             the val glyphs alone, recoloured to the site's
                                ink #23201c, for the header on cream.

Better still, ask for an SVG. There is no size at which a vector softens.
